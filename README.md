### 关于我

我是一名偏产品落地的全栈开发者，长期围绕 **AI 工具、前端工程化、管理后台、支付/钱包/交易系统、数据平台、多语言站点和浏览器效率工具** 做工程实践。

我喜欢把复杂流程拆成可验证、可复盘、可持续迭代的系统：从用户界面、业务流程、数据链路，到日志、缓存、超时、降级和自动化脚本，都尽量做到能解释、能定位、能优化。

#### 数据、支付与交易系统

- 支付、收银台、商户后台、钱包 App 等项目经验：关注交易链路、状态流转、风控信息、账务展示和用户操作闭环。

- AI Agent 跟单与交易工具：围绕信号跟踪、交易执行、通知提醒和命令行工具做自动化实践。

#### 全栈与工程基础设施
